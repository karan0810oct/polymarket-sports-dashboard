Live data availability depends on each provider, sport coverage, API quota and network access. Polymarket bid/ask are exchange order-book prices. The Odds API normally provides bookmaker BACK prices, not bookmaker LAY prices; missing prices are shown as “—”, never fabricated. This page runs on your device: a key entered here is stored in this browser and sent to The Odds API from the browser, so use a backend proxy if you need to keep the key confidential. Keep this page open for WebSocket-first live updates. If the live connection drops, REST order-book fallback runs every 15 seconds for visible markets; event catalogue refreshes every 3 minutes.
